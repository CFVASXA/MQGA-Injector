使用流程

  1. 选择注入模式（app.asar 替换 或 MinHook 内存 hook）
  2. 退出 QQ（点此退出全部 QQ）
  3. 「宿主管理」下载宿主
  4. 确认路径与版本
  5. 点「一键安装注入」
  6. 启动 QQ 验证效果
